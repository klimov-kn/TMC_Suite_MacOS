# TMCGROUT — входные данные (S-матрица, частотная область)

Вьювер `TMCGROUT.exe` строит графики элементов матрицы рассеяния (S-матрицы) по частоте.

## Файлы

| Файл | Формат | Что это |
|------|--------|---------|
| `rths25.soc` | `.soc` — **документ** | Текстовый файл оформления: тип осей, масштаб, цвета и **список кривых**. Сами данные не хранит — ссылается на `.s`-файл по имени. |
| `rths25.s` | `.s` — **данные S-матрицы** | Двоичный файл с комплексными значениями S-матрицы по частотам. На него ссылается `.soc`. |

> Последняя строка `rths25.soc` ссылается на `rths25.s` **по имени файла**, поэтому оба файла
> должны лежать рядом (так и есть). При переименовании одного — поправьте ссылку в `.soc`.

## Как посмотреть

1. Запустите `TMCGROUT.exe`.
2. **File → Open…** (Ctrl+O) → выберите `rths25.soc` — график построится сразу.
   - Либо откройте напрямую `rths25.s` (программа создаст для него документ).
3. Если кривая «уехала» за край — **View → Zoom → Auto X size** (Alt+X) и **Auto Y size** (Alt+Y).
4. **Edit → Characteristics** (Ctrl+D) — таблица кривых: включение/выключение, выбор входа/моды
   элемента S-матрицы.

Эти `.s`/`.soc` — результат расчёта ядра (H/X). Свои можно получить, посчитав `.tpl` в `PlanarRT_H`.
