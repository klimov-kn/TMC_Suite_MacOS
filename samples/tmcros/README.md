# TMCROS — входные данные (временно́й сигнал)

Вьювер `TMCROS.exe` строит графики временны́х сигналов и умеет восстанавливать из них S-матрицу
(**Edit → To S-matrix**).

## Файлы

| Файл | Формат | Что это |
|------|--------|---------|
| `poly.tos` | `.tos` — **документ** | Текстовый файл оформления и список кривых; ссылается на `.t`-файл по имени. |
| `poly.t` | `.t` — **сырой сигнал** | Текстовый файл сигнала: заголовок `#TMC_GraphicsOutputSignalFile` + таблица отсчётов (nT, блоки, значения). |

> `poly.tos` ссылается на `poly.t` по имени — держите файлы рядом (так и есть).

## Как посмотреть

1. Запустите `TMCROS.exe`.
2. **File → Open…** (Ctrl+O) → выберите `poly.tos` (готовый документ) или `poly.t` (сырой сигнал).
3. **View → Zoom → Auto X/Y size** при необходимости.
4. **View → Viewport** (Ctrl+H) — что отложено по Y (Signal/Amplitude/Phase/…) и единица оси X.
5. (Опционально) **Edit → To S-matrix** (Alt+T) — восстановить S-матрицу из сигнала и сохранить `.s`;
   полученный `.s` затем открывается в **TMCGROUT**.

Эти `.t`/`.tos` — результат расчёта ядра (H/X). Свои можно получить, посчитав `.tpl` в `PlanarRT_H`.
