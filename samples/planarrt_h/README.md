# PlanarRT_H — входные данные (H-мода)

Счётное ядро `tmc_rth.exe`. Единственный формат входа — текстовый шаблон **`.tpl`**
(перед расчётом проходит препроцессор PREPR: `#include`, `#define`, вычисление выражений).

## Файлы

| Файл | Что это |
|------|---------|
| `demo_h.tpl` | **Самодостаточный учебный пример.** Плоский волновод из двух металлических пластин, порт возбуждения слева, поглотители по краям. Маленькая сетка 200×100 (Δ=1 мм) — считается быстро. Не требует внешних файлов. |
| `TEST.TPL` | **Проверенный рабочий пример** (модель рупора). Точка входа. |
| `HORNS.H` | Подключается из `TEST.TPL`: константы геометрии (`#define`). |
| `CIR_QUAS.H` | Подключается из `TEST.TPL`: макрос `Wozmush` — разворачивается в полный расчётный шаг `#STEP`. |

`TEST.TPL` крупнее и считается дольше (сетка ~687×500); для первого запуска быстрее `demo_h.tpl`.

## Как запустить

1. Запустите `tmc_rth.exe` (`dist/win32/bin` или `dist/win64/bin`).
2. **File → Open…**, выберите `demo_h.tpl` (или `TEST.TPL`).
3. **Run** — начнётся расчёт. Прогресс и параметры сетки видны в **View → Statistics**.
4. По окончании рядом появятся выходные файлы с базовым именем из секции `#OUTPUT`
   (`demo_h.*` для учебного примера, `quasi0.*` для `TEST.TPL`).

## Что получится на выходе (вход для остальных программ)

- `*.t` / `*.tos` → открываются в **TMCROS** (временно́й сигнал);
- `*.s` / `*.soc` → открываются в **TMCGROUT** (S-матрица);
- `*.tf`, `*.AMP`, `*.FAZ` (от `FIELD_DISTRIBUTION_M`) → открываются в **FieldView** (поле).

## Структура `.tpl` (кратко)

```
#TMC_RT_H                ← обязательная сигнатура (первая строка)
#STEP
  #PARM … #END_PARM           — единицы, сетка (DELTA), время (TIME), частота (FREQ)
  #TOPOLOGY … #END_TOPOLOGY    — геометрия: BLOCK n; <элемент>; END_B
  #LINK_LIST … #END_LINK       — размещение блоков: T n; x0; y0;
  #OUTPUT … #END_OUTPUT        — какие файлы создавать
#END_STEP
#EOF
```

Элементы топологии: `RECT_STAT`, `CIRCLE_STAT`, `POLYGON_STAT` (материал `METAL`/`ABSORBER`
или выражение для неоднородной ε), порт `INPUT_X`. Полный разбор — `docs/user-manual/planar_rt_h.md`.
