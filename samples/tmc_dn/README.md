# TMC_DN — входные данные (диаграмма направленности)

Вьювер `TMC_DN.exe` рассчитывает и строит диаграмму направленности (ДН) антенной решётки,
показывает КНД/КИП/излучённую мощность, умеет вносить девиации и сравнивать с требуемой ДН.

## Файлы

| Файл | Формат | Что это |
|------|--------|---------|
| `r7.dop` | `.dop` — **документ** | Текстовый файл оформления и список кривых; ссылается на `r7.DAT` по имени. |
| `r7.DAT` | `.DAT` — **описание решётки** | Текстовое описание излучателей: координаты X/Y, амплитуда, фаза, угловой сектор. По нему считается ДН. |
| `r7.AMP` | `.AMP` — **амплитуда поля** | Файл распределения поля (амплитуда). |
| `r7.FAZ` | `.FAZ` — **фаза поля** | Файл распределения поля (фаза). |

> `r7.dop` ссылается на `r7.DAT` по имени — держите файлы рядом (так и есть).

## Как посмотреть

1. Запустите `TMC_DN.exe`.
2. **File → Open…** (Ctrl+O) → выберите `r7.dop` (готовый документ) или `r7.DAT` (сырое описание).
   Для большой решётки появится окно прогресса — дождитесь конца расчёта.
3. **View → Zoom → Auto X/Y size** при необходимости.
4. КНД (`Knd`, в т.ч. в дБ) и КИП (`Kip`) / **Emitted Power** — в правой части строки состояния.
5. **Edit → Characteristics** (Ctrl+D) — таблица кривых; оттуда запускаются девиации и сравнение
   с требуемой ДН.

> Примечание: в исходном наборе `r7.AMP`/`r7.FAZ` — это файлы поля формата
> `#TMC_GraphicsOutputFieldFile` (как у FieldView), а `r7.DAT` — текстовое описание решётки.
> Программа TMC_DN открывает именно `.DAT`: `.AMP` и `.FAZ` — файлы поля,
> частоту из них она не читает.
