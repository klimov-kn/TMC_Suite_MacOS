# PlanarRT_X — входные данные (X-мода)

Счётное ядро `tmc_rtx.exe`. Формат входа — тот же текстовый шаблон **`.tpl`**, что и у H-моды,
и **та же сигнатура `#TMC_RT_H`** (отдельной `#TMC_RT_X` нет). Поэтому один и тот же файл
открывается обоими ядрами; различается то, что считается «под капотом» (4 подтакта, 8 компонент
поля на узле, дополнительные типы блоков).

## Файлы

| Файл | Что это |
|------|---------|
| `demo_x.tpl` | **Самодостаточный учебный пример.** Плоский волновод + порт слева + поглотители, маленькая сетка (быстрый счёт). Внизу секции `#TOPOLOGY` — **закомментированные** примеры возможностей X-моды: подвижный блок `RECT_MOVE`, диэлектрик-распределение `E(x,y)`, второй порт `INPUT_Y`. Уберите `!` у нужного блока (и у соответствующей строки `T …` в `#LINK_LIST`), чтобы поэкспериментировать. Как есть — гарантированно считается. |
| `TEST.TPL`, `HORNS.H`, `CIR_QUAS.H` | Тот же проверенный рабочий комплект, что и в `PlanarRT_H/` — он корректно открывается и X-ядром. |

## Как запустить

1. Запустите `tmc_rtx.exe`.
2. **File → Open…**, выберите `demo_x.tpl` (или `TEST.TPL`).
3. **Run**. Из-за 8 компонент поля X-расчёт требует **больше памяти и времени**, чем H, при той
   же сетке — следите за `NumNode`/`Memory` в **View → Statistics**.
4. Выходные файлы получат базовое имя из `#OUTPUT` (`demo_x.*` / `quasi0.*`).

## Особенности X-моды

- Дополнительные элементы: подвижные `RECT_MOVE` / `CIRCLE_MOVE` / `POLYGON_MOVE`
  (в конце добавляются скорости `Vx; Vy; w;`) и второй порт `INPUT_Y`.
- Ядро также распознаёт блоки с суффиксом `_Y` (`RECT_STAT_Y` и т.п.) — их назначение
  уточняется у автора (К.Н. Климов); в учебном примере не используются.
- Диаграмма направленности (**View → Directional Pattern**) в текущей версии X может не давать
  результата — накопление данных для ДН отключено.

> 6 препроцессорных макросов X-моды — это деталь **сборки** ядра, а не работы с входными данными;
> на `.tpl` они не влияют. Полный разбор формата — `docs/user-manual/planar_rt_x.md`.
