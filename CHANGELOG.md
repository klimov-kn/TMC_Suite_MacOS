## [2.0.0] — 2026-10-31

Версия приведена к Windows-версии 5.0 и версии для Linux 2.0.0: тот же расчётный код, те же окна, панели и значки.
Перечень дефектов — в карточках [Issues](https://github.com/klimov-kn/TMC_Suite_MacOS/issues).

### Добавлено
- Интерфейс Windows-версии 5.0: тёмная тема, шрифты Inter и JetBrains Mono, новые значки панелей, индикаторы на кнопках
  (зелёный — включено или запущено), окно выбора цвета, единое окно «О программе», выбор языка (русский, английский).
- Значки программ для macOS: файлы `.icns` по сетке Apple (плитка с полем и тенью), каждый размер от 16 до 1024 точек
  нарисован из вектора, в том числе вторые размеры для экранов Retina. Значок в Dock берётся из `.icns`.
- Расчёт на видеокарте (OpenCL 1.2 из состава macOS): окно «Настройки → Вычисления», ключи `-GPU`, `-GPU:n`, `-CPU`.
  На Apple Silicon у видеокарты нет двойной точности: расчёт идёт на процессоре, окно называет причину.
- Многочастотный расчёт и падающая волна из файла, диаграмма направленности по границе, блоки больше 2³¹ узлов,
  ускоренное заполнение ε в несколько потоков.
- Замер времени расчёта: ключ `-Time`, кнопка «Calc. time…», отчёт `<задание>.timing_H_macos_arm64.txt` (Apple Silicon)
  или `…_macos_x64.txt` (Intel).
- TPL Designer в составе пакета: «Файл → Создать» в ядре открывает его. Чтение STEP через OpenCASCADE 7.9.
- FieldView на Qt RHI через Metal: тот же вид, что в Windows, история кадров, слежение за расчётом.
- Двойной щелчок по файлу в Finder открывает его в нужной программе пакета.
- Поставка: образ `.dmg` и архив `.zip`. В каждом Qt 6, OpenCASCADE, образцы заданий и руководство пользователя на
  русском и английском.

### Исправлено
- Все исправления ядер, библиотек и вьюверов Windows-версии по аудиту и ответам автора: физическая модель, порты,
  поглотитель, S-матрица, разбор заданий.
- Потоки текстовых файлов доводят запись до диска при `fflush`: задания с диаграммой направленности не падали на
  чтении `.t` («Can't read time»).
- Пакетный режим возвращает те же коды, что Windows-версия (0, 1, 2, 3), и пишет ход расчёта в терминал.
- Сборка больше не даёт предупреждений об устаревшем `sprintf` и о кодировке: рамки таблиц записаны кодами байтов,
  значения строк те же.

### Изменено
- Код разложен так же, как в Windows-версии; номера версий macOS идут отдельно: 2.0 соответствует Windows 5.0.
- Требуется macOS 13 Ventura или новее: библиотеки Qt 6.11 собраны с этой планкой.
- Лицензия Apache 2.0 вместо прежней академической.

### Удалено
- Ветки кода для Windows и Linux, наследие DOS и Windows 95, отладочные средства MFC, метки ClassWizard, прежний
  FieldView на OpenGL, средства проверки, мёртвый код, файлы вне сборки: 431 файлов кода вместо 555.
- Из репозитория убраны папки `docs`, `samples`, `tools`, `cmake`, `resources`: документация — на сайте
  [www.tamic.ru](https://www.tamic.ru), руководство и образцы — в поставках, сборка — в папках `build` и `installer`.

### Совместимость
- Файлы расчётной части совпадают с версией для Linux 2.0.0, которая сверена с Windows-версией 5.0 на 45 проверочных
  заданиях. Отличия только в именах платформы в отчёте о времени, снятых условиях, которые никогда не выполнялись, и
  записи рамок таблиц кодами.
- Выпуск собран кросс-набором osxcross и на настоящем маке не запускался: проверены сборка обеих архитектур без ошибок
  и предупреждений, состав пакетов, подпись, образ.
